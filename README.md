# Newcomer Banking Guide

A classroom Streamlit prototype for personalized U.S. banking guidance.

## Run locally

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

Open http://localhost:8501 if the browser does not open automatically.

All bank data is fictional demo data. The app does not collect real SSNs, passports, banking credentials, or credit information.
